# AgriTech - Smart Farming Ecosystem

A full-stack MERN application designed to empower farmers with digital tools:
- **Role-Based Authentication**: Farmer and Admin accounts with JWT security.
- **My Farms & Crop Monitoring**: Plot registration, land management, and real-time crop health telemetry.
- **Live Regional Weather**: Temperature, humidity, wind velocity, and field advisories.
- **Soil Testing & Crop Recommendation Engine**: Interactive pH analysis and fertilizer strategies.
- **Pest & Disease Directory**: Regional threat alerts with symptoms and chemical/biological remedies.
- **Agri-Store**: Certified seed and fertilizer marketplace with live order history.
- **Expert Forum**: Farmer consultation board with agronomist reply tooling.
- **Multilingual Support**: Dynamic English and Hindi localization.
